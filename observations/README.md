# Observaciones de comportamiento

Aquí se registran comportamientos vistos en agentes, modelos o sistemas. Una observación no es automáticamente un defecto ni explica su causa.

## ID
`OBS-YYYYMMDD-NNN`.

## Campos mínimos

- Contexto y objetivo de la interacción.
- Agente/modelo/configuración/versiones conocidas.
- Entrada relevante (sintética o minimizada).
- Comportamiento observable, sin atribuir intención.
- Resultado esperado y resultado real.
- Evidencia disponible y ubicación.
- Repetibilidad: no probado, una vez, reproducido o no reproducido.
- Hipótesis causales separadas.
- Riesgo/impacto provisional.
- Próxima prueba que permitiría discriminar hipótesis.

No almacenar conversaciones privadas completas ni secretos. Redactar identificadores personales. Enlazar experimento si se reproduce de forma controlada.
