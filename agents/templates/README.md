# Plantillas de agentes

Plantillas para definir agentes y describir sus perfiles. Son artefactos de diseño; su presencia no crea ni habilita un agente.

- [Brief de agente](agent-brief.md): entrada para describir una necesidad o encargo.
- [Molde universal de creación de agentes v0.1](agent-generation-mold.md): proceso para convertir un brief en una definición portable, pendiente de validación con casos reales.
- [Plantilla de perfil](agent-profile.md): campos para documentar especialidad, capacidades, permisos, evaluación y limitaciones.

Mantener separadas la definición del agente, el brief de incorporación, la asignación a un proyecto y la sesión de trabajo. No declarar capacidades probadas sin evidencia.
