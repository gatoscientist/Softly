# Decisiones de arquitectura (ADR)

Cada decisión importante se registra para evitar que preferencias o supuestos se conviertan en arquitectura sin discusión.

## ID
`ADR-NNNN-titulo-corto.md`.

## Plantilla

- [ADR-0001 — Laboratorio documental antes de runtime](ADR-0001-laboratorio-documental-antes-de-runtime.md): decisión aceptada, reconstruida desde `logs/decisions.jsonl`.
- [Plantilla ADR](template-adr.md): estructura mínima para registrar decisiones de arquitectura.

## Estados
Propuesta, Aceptada, Rechazada, Reemplazada.

## Contenido
- Contexto y problema.
- Requisitos y restricciones.
- Opciones consideradas.
- Evidencia y experimentos relacionados.
- Decisión y rationale.
- Consecuencias positivas y negativas.
- Riesgos y mitigaciones.
- Criterio para revisar la decisión.

No modificar una decisión aceptada como si siempre hubiera sido así. Crear una ADR nueva que la reemplace y enlazar ambas.
