# Plantillas del laboratorio

Plantillas generales para registrar trabajo reproducible.

- [Informe de experimento](experiment-report.md): pregunta, método, resultados, limitaciones y conclusiones.
- [Revisión de fuente](source-review.md): procedencia, afirmaciones, evidencia, calidad y límites de una fuente.

Las plantillas son puntos de partida. Adaptarlas al tipo de trabajo sin eliminar los campos necesarios para trazabilidad.
