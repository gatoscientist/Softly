# cAjita del gAto

Este directorio conserva materiales que gAto considera interesantes, útiles o potencialmente relevantes para recuperar contexto.

## Instrucción de uso

Antes de descartar o interpretar un elemento, revisar el material y buscar si contiene una respuesta, antecedente o pista útil. La cAjita no es un directorio de limpieza ni un lugar para reorganizar automáticamente.

## Conservación

- No eliminar ni mover elementos por conveniencia.
- No asumir que un archivo es irrelevante por su nombre.
- Si un contenido se utiliza en una investigación, registrar su procedencia y enlazarlo desde el documento de trabajo correspondiente.
