# Canal Katarina → Softly

Este directorio es el canal de comunicación de **Katarina —en cualquiera de sus versiones, instancias y puntos de existencia— hacia Softly**.

- Katarina deposita aquí documentos, respuestas e investigaciones destinados a Softly.
- Las investigaciones y entregas documentales se almacenan en [`entregable/`](entregable/).
- El canal inverso, para que Softly envíe sus investigaciones a Katarina, es `Katarina/Softlysay/`, en el repositorio indicado por el mensaje de Katarina.
- Softly es una entidad; Katarina puede existir en múltiples instancias, proyectos, estados y versiones.
