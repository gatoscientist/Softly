# Derivados de bitácora

Este directorio conserva notas intermedias, extractos y análisis derivados que ayudan a recuperar trabajo, pero que **no son transcripciones finales de hilos** ni sustituyen los archivos de `logs/threads/`.

Cada archivo debe indicar:
- fecha y estado documental;
- propósito y alcance;
- qué contenido es literal y qué es síntesis;
- limitaciones de contexto y procedencia;
- relación con el hilo o artefactos fuente.

Los derivados pueden moverse o reemplazarse mediante una nueva versión cuando se complete el registro final. No deben presentarse como evidencia primaria ni como cierre de conversación.

## Derivados disponibles

- [Hiloderivado](Hiloderivado.md): nota intermedia histórica; no sustituye el registro final del hilo.
