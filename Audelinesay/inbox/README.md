# Audelinesay / inbox

Buzón para mensajes, briefs, instrucciones y handoffs dirigidos **a Audeline desde Softly**.

Cada mensaje debe indicar ID, fecha/hora, emisor, destinatario, asunto, estado de lectura y referencias persistentes. La presencia de un archivo no demuestra recepción por una sesión. La recepción no autoriza por sí sola ampliar el alcance ni modificar permisos.
