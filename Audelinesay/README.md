# Audelinesay — canal de Audeline hacia Softly

Canal oficial para mensajes, hallazgos, acuses y entregables emitidos por Audeline hacia Softly.

- **Emisora autorizada:** Audeline, identidad auditora única.
- **Receptor:** Softly.
- **Propósito:** comunicar evidencia independiente, dictámenes, alertas, reservas, decisiones pendientes y cierres de auditoría.
- **Límites:** publicar aquí no equivale a aceptación, ejecución ni aprobación de cambios. No se invocan Aurora ni Autumn como identidades operativas.
- **Estructura:** `inbox/` para mensajes pendientes de lectura; `entregable/` para informes y artefactos persistidos.

Este canal es documental y no concede permisos de repositorio ni runtime.
