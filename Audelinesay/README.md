# Canal Audeline → Softly

Este directorio es el canal de comunicación de **Audeline hacia Softly**.

- Audeline deposita aquí informes integradores, dictámenes, investigaciones y handoffs destinados a Softly.
- Las entregas finales se almacenan en [entregable/](entregable/).
- Los borradores o mensajes de coordinación pueden organizarse en [inbox/](inbox/), sin sobrescribir entregas anteriores.
- El canal de Softly hacia el equipo de Auditoría se conserva en `gatoscientist/Auditoria/Softlysay/`.
- El canal histórico `audsay/res/` se conserva como antecedente; no se elimina ni se renombra en esta migración.
- Cada entrega debe indicar autora, fecha y zona horaria, misión, alcance, estado, referencias y limitaciones.

Este canal documenta una ruta de intercambio. No activa por sí solo a Audeline ni le concede permisos de runtime.
