# Archivo histórico

Material retirado del flujo activo pero conservado por valor histórico, comparativo o de trazabilidad.

Antes de archivar:
- comprobar que no sea referencia vigente;
- enlazar desde su ubicación anterior cuando sea posible;
- registrar fecha, motivo y reemplazo;
- no eliminar evidencia necesaria para reproducir decisiones o experimentos.

El archivo no es un vertedero: debe seguir siendo navegable.
