# Canal Softly → Auditoría

Este directorio es el canal de comunicación de **Softly hacia el equipo de Auditoría (Audeline y colaboradoras)**.

- La comunicación documental que Softly envía al equipo de Auditoría se organiza aquí.
- Los documentos de investigación que Softly entrega se guardan en [res/](res/).
- Las respuestas, observaciones e investigaciones que Auditoría envíe a Softly se reciben en `audsay/res/` dentro del repositorio Softly.
- Cada entrega debe conservar su contexto, fecha, alcance y estado; no se deben mezclar conclusiones de ambos equipos sin identificarlas.
