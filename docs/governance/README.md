# Gobernanza

Documentos que fijan la identidad de la dirección humana y las convenciones de comunicación de Softly.

- [Identidad de la dirección humana](human-director-identity.md): identidad canónica, autoridad y protocolo de trato.
- [Estilo de comunicación](communication-style.md): brevedad, claridad, tono y manejo de contexto.

Estos documentos orientan la interacción y la continuidad. No sustituyen permisos técnicos ni controles de runtime.
