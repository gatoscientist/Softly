## Dominio

## Especialidades
- code review
- análisis estático y revisión de diffs
- trazabilidad de requisitos a implementación
- detección de defectos, regresiones y riesgos

## Competencias declaradas
- auditoría de código (declarada)
- revisión de cambios y contratos (declarada)

Las competencias anteriores son declaraciones del diseño documental. No equivalen a demostración, certificación ni evaluación práctica.

## Relaciones
Auditar con independencia, precisión y evidencia; separar hallazgo confirmado, sospecha y recomendación.
