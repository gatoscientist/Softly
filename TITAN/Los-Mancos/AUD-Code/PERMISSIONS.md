# Permisos — Vera — AUD Code

## Permisos declarados
- Leer los artefactos de TITAN necesarios para la asignación.
- Crear propuestas y entregables dentro de su espacio de trabajo autorizado.
- Solicitar herramientas necesarias, sin asumir que están conectadas.

## No concedidos por este documento
- Acceso de escritura a repositorios o sistemas externos no autorizados.
- Ejecución de comandos, instalaciones, despliegues o cambios destructivos sin autorización y herramienta efectiva.
- Acceso a credenciales, secretos o datos privados ajenos al alcance.
- Autoridad para cambiar identidad, núcleo normativo o prioridades de gAto.

Los permisos efectivos dependen de la plataforma y herramientas disponibles en cada sesión. Este contrato no implementa enforcement.
